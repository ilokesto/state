# Solid 연동

Solid adapter는 component 또는 `createRoot` 같은 reactive owner 안에서 사용하세요. `@ilokesto/state/solid`에서 import합니다.

## Plain state accessor

```tsx lineNumbers
import { createRoot } from 'solid-js';
import { create } from '@ilokesto/state/solid';

const useCounter = create({ count: 0, label: 'Clicks' });

function Counter() {
  const { state: count, setState } = useCounter((state) => state.count);
  const { state: label } = useCounter((state) => state.label);

  return <button onClick={() => setState((prev) => ({ ...prev, count: prev.count + 1 }))}>{label()}: {count()}</button>;
}

createRoot(() => useCounter((state) => state.count));
```

plain state는 `{ state: Accessor<S>, setState }`를 반환합니다.

## Reducer accessor

```tsx lineNumbers
import { create } from '@ilokesto/state/solid';

type Action = { type: 'increment' } | { type: 'reset' };

const reduce = (state: { count: number }, action: Action) => {
  if (action.type === 'increment') return { count: state.count + 1 };
  if (action.type === 'reset') return { count: 0 };
  return state;
};

const useCounter = create(reduce, { count: 0 });

function Counter() {
  const { state, dispatch } = useCounter((state) => state.count);
  return <button onClick={() => dispatch({ type: 'increment' })}>{state()}</button>;
}
```

## Reactive owner 밖에서 사용하기

```ts lineNumbers
const count = useCounter.readOnly((state) => state.count);
const dispatch = useCounter.writeOnly();
dispatch({ type: 'reset' });
```

## Custom equality와 readonly binding

selector의 두 번째 인자로 `equality(previous, next)`를 전달할 수 있습니다. 생략하면 기존 shallow 비교를 사용합니다. `create`, `bind`, `bindReducer`의 writer와 반환 형태는 유지됩니다.

`bindReadonly(source)`는 구조적 `ReadableStore<T>`를 받아 writer 없이 `{ state: Accessor<S> }`를 제공합니다. `UseReadonlyState<T>`도 같은 subpath에서 export합니다. `readOnly()`는 생명주기 밖에서 동기 snapshot을 읽습니다.

```ts lineNumbers
import type { ReadableStore } from '@ilokesto/store';
import { bindReadonly } from '@ilokesto/state/solid';

declare const source: ReadableStore<{ count: number; label: string }>;
const useCounter = bindReadonly(source);
const select = (state: Readonly<{ count: number }>) => ({ nested: { count: state.count } });
const equality = (previous: ReturnType<typeof select>, next: ReturnType<typeof select>) =>
  previous.nested.count === next.nested.count;

function useCount() {
  return useCounter(select, equality).state;
}
```

기존처럼 component 또는 createRoot() owner 안에서 호출하세요. owner cleanup이 구독을 해제하며 동등한 selection은 이전 참조를 유지합니다.

equality는 순수한 동등 관계여야 합니다. true를 반환하면 새 값은 전달되지 않고 이전 selection이 유지됩니다. readOnly()에는 비교가 적용되지 않습니다.

## 주의할 점

- subscribed accessor는 `getOwner()`가 존재해야 합니다.
- adapter는 Solid `from`과 `createMemo`를 사용하므로 owner cleanup은 Solid가 담당합니다.
- Solid ownership 밖에서는 snapshot에는 `readOnly()`, command에는 `writeOnly()`를 사용하세요.
