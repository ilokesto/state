# Svelte 연동

Svelte adapter는 Svelte store 기대에 맞는 store object를 반환합니다. `@ilokesto/state/svelte`에서 import합니다.

## Plain writable store

```svelte lineNumbers
<script lang="ts">
  import { create } from '@ilokesto/state/svelte';

  const counter = create({ count: 0, label: 'Clicks' });
  const count = counter.select((state) => state.count);
  const increment = () => counter.update((state) => ({ ...state, count: state.count + 1 }));
</script>

<button on:click={increment}>
  {$count}
</button>
```

plain state는 writable이며 `set`, `update`, `setState`, `select`, `writeOnly`, `readOnly`를 포함합니다.

## Reducer readable store

```svelte lineNumbers
<script lang="ts">
  import { create } from '@ilokesto/state/svelte';

  type Action = { type: 'increment' } | { type: 'reset' };
  
  const reduce = (state: { count: number }, action: Action) => {
    if (action.type === 'increment') return { count: state.count + 1 };
    if (action.type === 'reset') return { count: 0 };
    return state;
  };

  const counter = create(reduce, { count: 0 });
  const count = counter.select((state) => state.count);
</script>

<button on:click={() => counter.dispatch({ type: 'increment' })}>
  {$count}
</button>
```

reducer state는 write가 `dispatch`를 통해 일어나야 하므로 readable입니다.

## 컴포넌트 밖에서 사용하기

```ts lineNumbers
const current = counter.readOnly((state) => state.count);
const setCounter = counter.writeOnly();
setCounter((state) => ({ ...state, count: state.count + 1 }));
```

## Custom equality와 readonly binding

selector의 두 번째 인자로 `equality(previous, next)`를 전달할 수 있습니다. 생략하면 기존 shallow 비교를 사용합니다. `create`, `bind`, `bindReducer`의 writer와 반환 형태는 유지됩니다.

`bindReadonly(source)`는 구조적 `ReadableStore<T>`를 받아 writer 없이 `Readable<ReadonlySnapshot<T>>`를 제공합니다. `UseReadonlyState<T>`도 같은 subpath에서 export합니다. `readOnly()`는 생명주기 밖에서 동기 snapshot을 읽습니다.

```ts lineNumbers
import type { ReadableStore } from '@ilokesto/store';
import { bindReadonly } from '@ilokesto/state/svelte';

declare const source: ReadableStore<{ count: number; label: string }>;
const useCounter = bindReadonly(source);
const select = (state: Readonly<{ count: number }>) => ({ nested: { count: state.count } });
const equality = (previous: ReturnType<typeof select>, next: ReturnType<typeof select>) =>
  previous.nested.count === next.nested.count;

const count = useCounter.select(select, equality);
const unsubscribe = count.subscribe(value => console.log(value.nested.count));
unsubscribe();
```

select(selector, equality?)는 subscriber마다 현재 값을 즉시 전달하고 독립적으로 구독합니다. unsubscribe로 구독을 해제하세요. readonly binding에는 set/update/setState/dispatch/writeOnly가 없습니다.

equality는 순수한 동등 관계여야 합니다. true를 반환하면 새 값은 전달되지 않고 이전 selection이 유지됩니다. readOnly()에는 비교가 적용되지 않습니다.

## 주의할 점

- `subscribe`는 Svelte 기대에 맞게 현재 state로 subscriber를 즉시 호출합니다.
- `select`는 하나의 projection을 위한 readable store를 만듭니다.
- reducer mode에서는 `dispatch`를 선호하세요. direct writable method는 노출되지 않습니다.
