# Vue 연동

Vue adapter는 `setup()` 또는 active `effectScope` 안에서 사용하세요. `@ilokesto/state/vue`에서 import합니다.

## Plain state composable

plain state는 `{ state: ComputedRef<S>, setState }`를 반환합니다.

```ts lineNumbers
import { create } from '@ilokesto/state/vue';

const useCounter = create({ count: 0, label: 'Clicks' });

export default {
  setup() {
    const { state: count, setState } = useCounter((state) => state.count);
    const { state: label } = useCounter((state) => state.label);
    const increment = () => setState((prev) => ({ ...prev, count: prev.count + 1 }));

    return { count, label, increment };
  },
};
```

`state`는 `ComputedRef`입니다. template에서는 자연스럽게 unwrap되고, script code에서는 `state.value`로 읽을 수 있습니다.

## Reducer composable

```ts lineNumbers
import { create } from '@ilokesto/state/vue';

type Action = { type: 'increment' } | { type: 'reset' };

const reduce = (state: { count: number }, action: Action) => {
  if (action.type === 'increment') return { count: state.count + 1 };
  if (action.type === 'reset') return { count: 0 };
  return state;
};

const useCounter = create(reduce, { count: 0 });

export function useCounterActions() {
  const { state, dispatch } = useCounter((state) => state.count);
  const increment = () => dispatch({ type: 'increment' });
  return { count: state, increment };
}
```

## Vue scope 밖에서 사용하기

Vue reactive call은 `setup()`/`effectScope` 밖에서 의도적으로 error를 던집니다. module code에서는 sync helper를 사용하세요.

```ts lineNumbers
const count = useCounter.readOnly((state) => state.count);
const dispatch = useCounter.writeOnly();
dispatch({ type: 'reset' });
```

## Custom equality와 readonly binding

selector의 두 번째 인자로 `equality(previous, next)`를 전달할 수 있습니다. 생략하면 기존 shallow 비교를 사용합니다. `create`, `bind`, `bindReducer`의 writer와 반환 형태는 유지됩니다.

`bindReadonly(source)`는 구조적 `ReadableStore<T>`를 받아 writer 없이 `{ state: ComputedRef<S> }`를 제공합니다. `UseReadonlyState<T>`도 같은 subpath에서 export합니다. `readOnly()`는 생명주기 밖에서 동기 snapshot을 읽습니다.

```ts lineNumbers
import type { ReadableStore } from '@ilokesto/store';
import { bindReadonly } from '@ilokesto/state/vue';

declare const source: ReadableStore<{ count: number; label: string }>;
const useCounter = bindReadonly(source);
const select = (state: Readonly<{ count: number }>) => ({ nested: { count: state.count } });
const equality = (previous: ReturnType<typeof select>, next: ReturnType<typeof select>) =>
  previous.nested.count === next.nested.count;

function useCount() {
  return useCounter(select, equality).state;
}
```

기존처럼 setup() 또는 active effectScope() 안에서 호출하세요. scope 종료 시 구독을 해제하며 동등한 selection은 이전 참조를 유지합니다.

equality는 순수한 동등 관계여야 합니다. true를 반환하면 새 값은 전달되지 않고 이전 selection이 유지됩니다. readOnly()에는 비교가 적용되지 않습니다.

## Async resource composable

`bindResource(resource)`는 기존 readonly composable에 타입이 있는 `run(input, options?)`을 추가한 `UseResource<Input, Output>`을 반환합니다. `setup`에서 호출하면 `ComputedRef<ResourceState<Output>>`를 받습니다. selector와 custom equality도 지원합니다. 관찰만 필요하면 `bindReadonly(resource.store)`도 동일하게 사용할 수 있습니다.

다음 예제는 서버 없이 성공과 실패를 직접 실행합니다.

```vue lineNumbers
<script setup lang="ts">
import { createResource } from '@ilokesto/state';
import { bindResource } from '@ilokesto/state/vue';

const request = createResource(async (shouldFail: boolean) => {
  if (shouldFail) throw new Error('Try again');
  return 'Loaded';
});
const useRequest = bindResource(request);
const { state } = useRequest();
</script>

<template>
  <p v-if="state.status === 'pending'">Loading...</p>
  <p v-else-if="state.status === 'error'">{{ String(state.error) }}</p>
  <p v-else-if="state.status === 'success'">{{ state.data }}</p>
  <p v-else>Choose an action</p>
  <button @click="useRequest.run(false)">Load / retry</button>
  <button @click="useRequest.run(true)">Fail</button>
</template>
```

retry는 `run`을 다시 호출합니다. Vue scope 종료는 구독만 해제하고 실행은 취소하지 않으므로 다른 component가 shared resource를 계속 사용할 수 있습니다. binding 생성은 실행을 시작하거나 소유권을 가져오지 않습니다. `cancel`/`dispose`는 소유자만 호출합니다. resource에서 직접 시작한 실행도 관찰합니다. 이 composable에는 React Suspense 동작이 없습니다.

## 주의할 점

- reactive read는 `getCurrentScope()`가 존재해야 합니다.
- cleanup은 `onScopeDispose`에 등록됩니다. subscribed read를 Vue scope 밖에서 우회하지 마세요.
- one-time read에는 `readOnly()`를 사용하세요. 이 값은 reactive하지 않습니다.
