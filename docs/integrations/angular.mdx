# Angular

Use the Angular adapter where Angular can provide cleanup through an injection context or explicit `DestroyRef`. Import from `@ilokesto/state/angular`.

## Plain state signal

```ts lineNumbers
import { Component, DestroyRef, inject } from '@angular/core';
import { create } from '@ilokesto/state/angular';

const useCounter = create({ count: 0, label: 'Clicks' });

@Component({ selector: 'counter-view', template: `<button (click)="inc()">{{ label() }}: {{ count() }}</button>` })
export class CounterView {
  private destroyRef = inject(DestroyRef);
  private countResult = useCounter((state) => state.count, { destroyRef: this.destroyRef });
  private labelResult = useCounter((state) => state.label, { destroyRef: this.destroyRef });

  count = this.countResult.state;
  label = this.labelResult.state;
  inc = () => this.countResult.setState((state) => ({ ...state, count: state.count + 1 }));
}
```

Plain state returns `{ state: Signal<S>, setState, subscribe }`.

## Reducer signal

```ts lineNumbers
import { create } from '@ilokesto/state/angular';

type Action = { type: 'increment' } | { type: 'reset' };

const reduce = (state: { count: number }, action: Action) => {
  if (action.type === 'increment') return { count: state.count + 1 };
  if (action.type === 'reset') return { count: 0 };
  return state;
};

const useCounter = create(reduce, { count: 0 });

export class ReducerCounter {
  private result = useCounter((state) => state.count);
  count = this.result.state;
  increment = () => this.result.dispatch({ type: 'increment' });
}
```

## Outside Angular lifecycle

```ts lineNumbers
const count = useCounter.readOnly((state) => state.count);
const dispatch = useCounter.writeOnly();
dispatch({ type: 'reset' });
```

## Custom equality and readonly binding

Pass `equality(previous, next)` as the selector's second argument. Omitting it keeps the existing shallow comparison. The writers and result shapes from `create`, `bind`, and `bindReducer` stay unchanged.

`bindReadonly(source)` accepts a structural `ReadableStore<T>` and provides `{ state: Signal<S>, subscribe }` without a writer. `UseReadonlyState<T>` is exported from the same subpath. Use `readOnly()` for synchronous snapshots outside the lifecycle.

```ts lineNumbers
import type { ReadableStore } from '@ilokesto/store';
import { bindReadonly } from '@ilokesto/state/angular';

declare const source: ReadableStore<{ count: number; label: string }>;
const useCounter = bindReadonly(source);
const select = (state: Readonly<{ count: number }>) => ({ nested: { count: state.count } });
const equality = (previous: ReturnType<typeof select>, next: ReturnType<typeof select>) =>
  previous.nested.count === next.nested.count;

function useCount(destroyRef: import('@angular/core').DestroyRef) {
  return useCounter(select, equality, { destroyRef }).state;
}
```

Existing (selector, options) calls remain valid. Pass custom equality as (selector, equality, options?). An injection context or explicit DestroyRef is still required; destruction unsubscribes.

Equality must be a pure equivalence relation. Returning true suppresses delivery and retains the previous selection. Equality does not apply to readOnly().

## Async resource signal

`bindResource(resource)` returns `UseResource<Input, Output>`: the readonly signal factory plus typed `run(input, options?)`. In an injection context, `useRequest().state` is a `Signal<ResourceState<Output>>`. An explicit `{ destroyRef }`, selectors, equality and `bindReadonly(resource.store)` keep their existing contracts.

This standalone component can exercise success, error and retry without a server:

```ts lineNumbers
import { Component, computed } from '@angular/core';
import { createResource } from '@ilokesto/state';
import { bindResource } from '@ilokesto/state/angular';

const request = createResource(async (shouldFail: boolean) => {
  if (shouldFail) throw new Error('Try again');
  return 'Loaded';
});
const useRequest = bindResource(request);

@Component({
  selector: 'resource-panel',
  standalone: true,
  template: `
    <p>{{ message() }}</p>
    <button (click)="load(false)">Load / retry</button>
    <button (click)="load(true)">Fail</button>
  `,
})
export class ResourcePanel {
  readonly state = useRequest().state;
  readonly message = computed(() => {
    const current = this.state();
    if (current.status === 'pending') return 'Loading...';
    if (current.status === 'error') return String(current.error);
    if (current.status === 'success') return current.data;
    return 'Choose an action';
  });
  load(shouldFail: boolean) { void useRequest.run(shouldFail); }
}
```

Retry calls `run` again. `DestroyRef` releases the subscription, not the shared execution. The binding never automatically calls `cancel`/`dispose`; that decision belongs to the resource owner. Runs started on the resource itself remain observable. Angular signals represent pending/error explicitly rather than throwing React Suspense promises.

## Caveats

- Without `{ destroyRef }`, the adapter calls `inject(DestroyRef)` and therefore needs an injection context.
- Cleanup is registered with `destroyRef.onDestroy(unsubscribe)`.
- The adapter result exposes `subscribe` for low-level integration, but prefer signals for templates.
