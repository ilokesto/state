# Solid

Use the Solid adapter inside a component or another reactive owner such as `createRoot`. Import from `@ilokesto/state/solid`.

## Plain state accessor

```tsx lineNumbers
import { createRoot } from 'solid-js';
import { create } from '@ilokesto/state/solid';

const useCounter = create({ count: 0, label: 'Clicks' });

function Counter() {
  const { state: count, setState } = useCounter((state) => state.count);
  const { state: label } = useCounter((state) => state.label);

  return <button onClick={() => setState((prev) => ({ ...prev, count: prev.count + 1 }))}>{label()}: {count()}</button>;
}

createRoot(() => useCounter((state) => state.count));
```

Plain state returns `{ state: Accessor<S>, setState }`.

## Reducer accessor

```tsx lineNumbers
import { create } from '@ilokesto/state/solid';

type Action = { type: 'increment' } | { type: 'reset' };

const reduce = (state: { count: number }, action: Action) => {
  if (action.type === 'increment') return { count: state.count + 1 };
  if (action.type === 'reset') return { count: 0 };
  return state;
};

const useCounter = create(reduce, { count: 0 });

function Counter() {
  const { state, dispatch } = useCounter((state) => state.count);
  return <button onClick={() => dispatch({ type: 'increment' })}>{state()}</button>;
}
```

## Outside reactive owner

```ts lineNumbers
const count = useCounter.readOnly((state) => state.count);
const dispatch = useCounter.writeOnly();
dispatch({ type: 'reset' });
```

## Custom equality and readonly binding

Pass `equality(previous, next)` as the selector's second argument. Omitting it keeps the existing shallow comparison. The writers and result shapes from `create`, `bind`, and `bindReducer` stay unchanged.

`bindReadonly(source)` accepts a structural `ReadableStore<T>` and provides `{ state: Accessor<S> }` without a writer. `UseReadonlyState<T>` is exported from the same subpath. Use `readOnly()` for synchronous snapshots outside the lifecycle.

```ts lineNumbers
import type { ReadableStore } from '@ilokesto/store';
import { bindReadonly } from '@ilokesto/state/solid';

declare const source: ReadableStore<{ count: number; label: string }>;
const useCounter = bindReadonly(source);
const select = (state: Readonly<{ count: number }>) => ({ nested: { count: state.count } });
const equality = (previous: ReturnType<typeof select>, next: ReturnType<typeof select>) =>
  previous.nested.count === next.nested.count;

function useCount() {
  return useCounter(select, equality).state;
}
```

Call inside a component or createRoot() owner, as before. Owner cleanup unsubscribes, and equal selections retain the previous reference.

Equality must be a pure equivalence relation. Returning true suppresses delivery and retains the previous selection. Equality does not apply to readOnly().

## Async resource accessor

`bindResource(resource)` returns `UseResource<Input, Output>`: the readonly accessor factory plus `run(input, options?)`. Call it inside a Solid owner to receive an `Accessor<ResourceState<Output>>`; selectors and equality retain their existing contracts. `bindReadonly(resource.store)` also works for observation alone.

The following component uses native reactive derivation and offers both outcomes without a server:

```tsx lineNumbers
import { createMemo } from 'solid-js';
import { createResource } from '@ilokesto/state';
import { bindResource } from '@ilokesto/state/solid';

const request = createResource(async (shouldFail: boolean) => {
  if (shouldFail) throw new Error('Try again');
  return 'Loaded';
});
const useRequest = bindResource(request);

export function ResourcePanel() {
  const { state } = useRequest();
  const message = createMemo(() => {
    const current = state();
    if (current.status === 'pending') return 'Loading...';
    if (current.status === 'error') return String(current.error);
    if (current.status === 'success') return current.data;
    return 'Choose an action';
  });
  return (
    <section>
      <p>{message()}</p>
      <button onClick={() => useRequest.run(false)}>Load / retry</button>
      <button onClick={() => useRequest.run(true)}>Fail</button>
    </section>
  );
}
```

The binding does not use Solid's separate `createResource` API or emulate React Suspense. Retry is another `run`. Owner cleanup unsubscribes without cancelling a borrowed resource; only the resource owner calls `cancel`/`dispose`. A direct resource run is observable too.

## Caveats

- Subscribed accessors require `getOwner()` to exist.
- The adapter uses Solid `from` and `createMemo`, so owner cleanup belongs to Solid.
- Outside Solid ownership, use `readOnly()` for snapshots and `writeOnly()` for commands.
