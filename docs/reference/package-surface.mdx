# Package surface

The ten public entrypoint paths are defined by this package's `package.json` exports. Import framework-neutral construction from the root and framework adapters from their subpaths.

## Entry point matrix

| Import | Purpose |
|---|---|
| `@ilokesto/state` | Framework-neutral `Store`, `createStore`, `createReducer`, `pipe`, `definePipeableMiddleware`, `PipeConfigurationError`, and `dispose`, plus their public state contracts. |
| `@ilokesto/state/react` | React `create`, `bind`, `bindReducer` and `UseState`, `UseReducer` types. |
| `@ilokesto/state/vue` | Vue `create`, `bind`, `bindReducer` and `UseState`, `UseReducer` types. |
| `@ilokesto/state/svelte` | Svelte `create`, `bind`, `bindReducer` and `UseState`, `UseReducer` types. |
| `@ilokesto/state/solid` | Solid `create`, `bind`, `bindReducer` and `UseState`, `UseReducer` types. |
| `@ilokesto/state/angular` | Angular `create`, `bind`, `bindReducer` and `AngularOptions`, `UseState`, `UseReducer` types. |
| `@ilokesto/state/middleware` | Registered middleware, store disposal, and middleware types. |
| `@ilokesto/state/utils` | Pipe composition, memory persistence and deterministic testing helpers. |
| `@ilokesto/state/adaptor` | `adaptor`; requires the optional `immer` peer. |
| `@ilokesto/state/package.json` | Package metadata export for tooling that needs this package manifest. |

## Middleware exports

`@ilokesto/state/middleware` exports `debounce`, `throttle`, `devtools`, `dispose`, `history`, `HistoryConfigurationError`, `logger`, `persist`, `PersistError`, `jsonStorage`, `cookieStorage`, `indexedDBStorage`, `memoryStorage`, and `validate`.

Its public types are `HistoryControls`, `HistoryOptions`, `HistoryStore`, `CookieStorageOptions`, `IndexedDBStorageOptions`, `PersistedValue`, `PersistStorage`, `PersistStorageFactory`, `PersistConflictPolicy`, `PersistControls`, `PersistDecoder`, `PersistDecoderStateDiagnostic`, `PersistMigration`, `PersistRehydrateOptions`, `PersistStatus`, `PersistStore`, and `SafePersistConfig`.

Storage selection uses `SafePersistConfig.storage`, a lazy adapter factory. The old local/session/cookie configuration and rehydration callback types are not exports; use the storage adapters and explicit persistence controls instead.

## Utility exports

`@ilokesto/state/utils` exports `pipe`, `definePipeableMiddleware`, `PipeConfigurationError`, `memoryStorage`, and `createStoreTestHarness`. See [Testing and measurement](/en/state/utility/testing).

Its public types are `Pipe`, `PipeAnyMiddleware`, `PipeBuilder`, `PipeCapability`, `PipeConfigurationErrorCode`, `PipeDuplicatePolicy`, `PipeMiddleware`, `PipeMiddlewareConflictDiagnostic`, `PipeMiddlewareMetadata`, `StoreTestHarness`, and `StoreWaitOptions`.

## Root and framework entrypoints

Import framework-neutral construction APIs from the root. Framework adapter APIs such as `create`, `bind`, and `bindReducer` come from a framework subpath, never the root.

Root runtime exports are `Store`, `createStore`, `createReducer`, `pipe`, `definePipeableMiddleware`, `PipeConfigurationError`, and `dispose`. Root type exports are `ReadableStore`, `StoreApi`, `Listener`, `Unsubscribe`, `SetStateAction`, `Selector`, `SelectorListener`, `EqualityFn`, `Middleware`, `ReducerState`, `ReduceFn`, and `ReducerAction`. Pipe and testing types come from `/utils`, and persistence types come from `/middleware`.

```ts lineNumbers
// Available from the framework subpath
import { create } from '@ilokesto/state/react';
import { logger } from '@ilokesto/state/middleware';
```

Use `createStore` or `createReducer` from the root and connect the result with `bind` or `bindReducer` from a framework subpath. See [Vanilla state and binding](/en/state/reference/vanilla) and the [migration guide](/en/state/advanced/migration).

## Peer dependencies

Framework peers are optional: install only the adapter framework you use. `immer` is optional and only needed when you use `adaptor` from `@ilokesto/state/adaptor`.
